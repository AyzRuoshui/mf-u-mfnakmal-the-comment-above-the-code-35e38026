## Overview

`main.ts` writes a single-line comment (at most 200 UTF-8 characters) imagining what a working developer actually left above fragile production code.

## Usage

Runs directly on Node.js 22.18+ (including Node 24):

```bash
node main.ts
```

### Output path options

- `--out <path>` / `--output <path>` / `-o <path>`: write directly to `<path>`
- `--out-dir <dir>`: write to `<dir>/entry.txt`
- `MAKEFUN_OUTPUT_DIR`: write to `$MAKEFUN_OUTPUT_DIR/entry.txt`
- Default: `/output/entry.txt`
